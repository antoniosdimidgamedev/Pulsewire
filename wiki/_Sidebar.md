# Pulsewire Wiki

This is the documentation wiki for Pulsewire, a self-hosted team messaging
server with a keyboard-driven terminal client, a browser-based management
dashboard, and a native Android client.

## Contents

- [Home](Home.md) — Welcome and overview
- [Server Setup](Server-Setup.md) — Install, configure, and run the server
- [LAN Deployment](LAN-Deployment.md) — Reach the server from phones and laptops
- [Android Client](Android-Client.md) — Native Android app setup and scope
- [API Reference](API-Reference.md) — `/v1` REST API endpoints
- [Security](Security.md) — Encryption, authentication, and threat model
- [Dashboard](Dashboard.md) — Using the management dashboard
